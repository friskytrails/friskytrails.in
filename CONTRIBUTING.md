# Contributing to FriskyTrails 🏔️

Thank you for your interest in contributing to FriskyTrails! We welcome contributions from the community to help make our adventure and tour booking platform even better.

## 🤝 How to Contribute

### 1. Reporting Bugs
- Use the [GitHub Issues](https://github.com/your-username/friskytrails.in/issues) to report bugs.
- Provide a clear description of the issue, steps to reproduce, and expected vs. actual behavior.
- Include screenshots or recordings if applicable.

### 2. Suggesting Enhancements
- Open a GitHub Issue with the tag `enhancement`.
- Explain why this feature would be useful and how it should work.

### 3. Submitting Pull Requests
- Fork the repository.
- Create a new branch for your feature or fix (`git checkout -b feature/amazing-feature` or `git checkout -b fix/bug-description`).
- Ensure your code follows the existing style and passes all linting checks.
- Commit your changes with descriptive messages.
- Push your branch and open a Pull Request (PR) against the `main` branch.

## 💻 Development Setup

Please refer to the [README.md](README.md) for detailed instructions on setting up the frontend and backend.

### Prerequisites
- **Node.js**: v18+
- **Database**: MongoDB Atlas
- **Assets**: Cloudinary

### Linting & Formatting
We use ESLint to maintain code quality. Please run the following before submitting a PR:
```bash
npm run lint
```

## 🎨 Styling & Design
- Use **Tailwind CSS** for styling components.
- For animations, prioritize **GSAP** and **Framer Motion**.
- Ensure all designs are responsive and premium in aesthetic.

## 📁 Repository Structure
- `src/`: React frontend source.
- `backend/`: Node.js/Express backend source.
- `public/`: Static assets.

## 📜 Code of Conduct
By participating in this project, you agree to abide by our code of conduct. Please be respectful and professional in all interactions.
